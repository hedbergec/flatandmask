# flatandmask

PowerShell + macOS tools to flatten nested JSON/CSV/Excel and deterministically mask PII.

This repository contains:

- `flatandmask.ps1` — original PowerShell processor
- `flatandmask_gui.ps1` — GUI wrapper for interactive input on Windows
- `flatandmask_run.bat` — launcher for double-click runs on Windows
- `examples/` — sample JSON/CSV and complex test inputs
- `apple/` — macOS Bash wrapper and Python implementation
- `EXAMPLES_AND_EVALUATION.md` — notes, examples, and test instructions

Note: this project was entirely "vibe coded".
